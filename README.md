# Online Appointment Booking System

## Project Overview

The Online Appointment Booking System is a web-based application that enables customers to book appointments online while allowing administrators to manage appointments, services, staff, and users.

This project is being developed as a group project using HTML, CSS, JavaScript, PHP, and MySQL.

---

## Objectives

- Allow customers to register and log in.
- Allow customers to book appointments.
- Allow administrators to manage appointments.
- Manage services and staff.
- Generate reports.
- Improve appointment scheduling efficiency.
